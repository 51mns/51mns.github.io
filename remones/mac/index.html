Mac アプリ「Remones Host」

iPhone・iPad の Remones から操作する Mac に入れるアプリです。接続を受け付け、Mac の画面と音声を送り、iPhone からの入力を Mac に伝えます。

ダウンロード準備中（まだ配布していません）

現在、配布の準備中です。公開したらこのページからダウンロードできるようになります。

動作環境

MacmacOS 15 以降
iPhone・iPadiOS / iPadOS 18 以降の Remones アプリ
ネットワーク同じ Wi-Fi などのローカルネットワーク。外出先からは Tailscale などの VPN（説明）
必要な権限画面収録（必須）、アクセシビリティ（操作する場合）

Remones は、自分が所有する Mac、または操作する権限のある Mac でのみ使ってください。

インストール

  1. ダウンロードして「アプリケーション」へ

    上のボタンからファイルをダウンロードして開き、「Remones Host」を「アプリケーション」フォルダに移動します。

  2. はじめて開く

    「アプリケーション」フォルダから「Remones Host」を開きます。「インターネットからダウンロードされたアプリケーションです」と確認されたら「開く」を選びます。

    ネットワークの接続について macOS から確認が表示された場合は、許可してください。許可しないと iPhone から見つけられません。

権限の許可

Mac の画面を送ったり、iPhone からの操作を Mac に伝えたりするには、macOS の許可が必要です。どちらも「システム設定」→「プライバシーとセキュリティ」で設定します。Remones Host のウインドウにある設定ボタンからも開けます。

  1. 画面収録（必須）

    「画面収録とシステムオーディオ録音」で Remones Host をオンにします。Mac の画面を iPhone に映すために使います。

    許可しないと、iPhone に Mac の画面が表示されません（「Macで画面収録を許可してください」と表示されます）。

  2. アクセシビリティ（操作する場合）

    「アクセシビリティ」で Remones Host をオンにします。iPhone からのキーボードやポインタの操作を Mac に伝えるために使います。

    許可しなくても、画面を見ることはできます。ただしキーボードやポインタでの操作はできません。

  3. Remones Host を開き直す

    画面収録を許可したあとは、Remones Host をいったん終了して、もう一度開いてください。macOS の仕組み上、開き直すまで許可が反映されないことがあります。

Remones が画面や入力を使うのは、あなたが承認した iPhone・iPad と接続しているあいだだけです。画面や入力の内容が開発者のサーバーに送られることはありません。

iPhone とペアリング

  1. iPhone で Mac を追加

    iPhone の Remones で Home の「＋」をタップし、「近くのMac」から Mac を選びます。見つからない場合は、Mac の IP アドレスかホスト名を入力して追加できます。

  2. コードを確かめる

    iPhone にペアリングコードが表示されます。Mac にも同じコードが表示されるので、一致していることを確認します。

  3. Mac で承認

    Mac に表示される確認で承認します。Always Allow を選ぶと、この iPhone を登録して、次回から承認なしで接続できます。Approve Once はその回だけ許可します。

    心当たりのない接続は Reject で拒否してください。

登録した iPhone は、Mac 側の一覧から削除できます。iPhone 側では、Home の Mac の「…」メニューから登録を解除できます。

アップデート

iPhone の Remones をアップデートしたあとに、Mac 側が古いと接続できないことがあります。「HostとRemonesのバージョンを確認してください」と表示されたら、Mac アプリも最新にしてください。

  1. 最新版をダウンロード

    このページから最新版をダウンロードします。

  2. 入れ替える

    Remones Host を終了してから、「アプリケーション」フォルダのアプリを新しいものに置き換えます。

  3. 開いて権限を確認

    Remones Host を開きます。画面収録やアクセシビリティの許可が外れていたら、もう一度許可して開き直してください。ペアリングはそのまま使えます。

うまくいかないとき

iPhone から Mac が見つからない

  • iPhone と Mac が同じ Wi-Fi（同じネットワーク）につながっているか確認してください。
  • iPhone の「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で Remones がオンになっているか確認してください。オフだと近くの Mac を探せません。
  • Mac で Remones Host が起動しているか、Mac がスリープしていないか確認してください。
  • 見つからない場合は、Home の「＋」から Mac の IP アドレスかホスト名を入力して追加できます。
  • 別のネットワークから接続する場合は Tailscale を使う方法をご覧ください。

画面が真っ黒・何も映らない

画面収録が許可されていない可能性があります。権限の許可を確認し、許可したあとに Remones Host を開き直してください。

画面は見えるが操作できない

アクセシビリティが許可されているか確認してください。ほかの iPhone・iPad が同じ Mac を操作している場合は、そちらを閉じてからもう一度お試しください。

「バージョンを確認してください」と表示される

Mac アプリが古い可能性があります。アップデートの手順で最新にしてください。

解決しないときは、サポートをご覧ください。

The Mac app: Remones Host

Install it on the Mac you want to control from Remones on your iPhone or iPad. It accepts connections, streams the Mac’s screen and sound, and passes your input to the Mac.

Requirements

MacmacOS 15 or later
iPhone and iPadThe Remones app on iOS / iPadOS 18 or later
NetworkA local network such as the same Wi-Fi. From elsewhere, a VPN such as Tailscale (guide)
PermissionsScreen Recording (required), Accessibility (to control the Mac)

Use Remones only with Macs you own or are authorized to control.

Install

  1. Download and move to Applications

    Download the file with the button above, open it, and move Remones Host to your Applications folder.

  2. Open it for the first time

    Open Remones Host from the Applications folder. If macOS says it was downloaded from the internet, choose Open.

    If macOS asks about network access, allow it. Otherwise your iPhone can’t find the Mac.

Permissions

To share the Mac’s screen and pass your input to it, macOS needs your permission. Both are in System Settings → Privacy & Security. The buttons in the Remones Host window open them too.

  1. Screen Recording (required)

    Turn on Remones Host under Screen & System Audio Recording. This is used to show the Mac’s screen on your iPhone.

    Without it, your iPhone can’t show the Mac’s screen (Remones says “Allow Screen Recording on your Mac”).

  2. Accessibility (to control the Mac)

    Turn on Remones Host under Accessibility. This is used to pass keyboard and pointer input from your iPhone to the Mac.

    Without it you can still view the screen, but you can’t type or use the pointer.

  3. Quit and reopen Remones Host

    After allowing Screen Recording, quit Remones Host and open it again. macOS may not apply the permission until the app is reopened.

Remones uses the screen and input only while connected to an iPhone or iPad you approved. Screen and input content is never sent to a developer server.

Pair with your iPhone

  1. Add the Mac on your iPhone

    In Remones on your iPhone, tap “+” on Home and choose your Mac under Nearby Macs. If it isn’t listed, add it by entering the Mac’s IP address or host name.

  2. Check the code

    Your iPhone shows a pairing code. The Mac shows the same code — make sure they match.

  3. Approve on the Mac

    Approve the request on the Mac. Always Allow saves this iPhone so it can connect without approval next time. Approve Once allows this connection only.

    If you don’t recognise the request, choose Reject.

You can remove a saved iPhone from the list on the Mac. On the iPhone, remove a Mac from its “…” menu on Home.

Updating

After you update Remones on your iPhone, an older Mac app may fail to connect. If Remones asks you to check the Host and Remones versions, update the Mac app too.

  1. Download the latest version

    Download the latest version from this page.

  2. Replace the app

    Quit Remones Host, then replace the app in your Applications folder with the new one.

  3. Open it and check permissions

    Open Remones Host. If Screen Recording or Accessibility is no longer allowed, allow it again and reopen the app. Your pairings keep working.

Troubleshooting

My iPhone can’t find the Mac

  • Make sure your iPhone and Mac are on the same Wi-Fi network.
  • On your iPhone, check Settings → Privacy & Security → Local Network and make sure Remones is on. Without it, Remones can’t look for nearby Macs.
  • Make sure Remones Host is running on the Mac and the Mac isn’t asleep.
  • You can also tap “+” on Home and enter the Mac’s IP address or host name.
  • To connect from a different network, see using Tailscale.

The screen is black

Screen Recording is probably not allowed. Check Permissions, then quit and reopen Remones Host.

I can see the screen but can’t control it

Check that Accessibility is allowed. If another iPhone or iPad is controlling the same Mac, close it there and try again.

Remones asks me to check versions

The Mac app is probably out of date. Follow the steps in Updating.

はじめかた

はじめて Remones を使うときの手順です。iPhone・iPad と Mac を手もとに用意して、同じ Wi-Fi につないでおくとスムーズです。

手順

  1. 1. Mac アプリを入れる
  2. 2. 権限を許可する
  3. 3. Mac を追加する
  4. 4. Mac で承認する
  5. 5. 開く

1. Mac アプリを入れる

操作したい Mac で、このページのアドレスを開いてください。

51mns.github.io/remones/mac/

Mac アプリ「Remones Host」をダウンロードして、「アプリケーション」フォルダに入れ、開きます。詳しくは Mac アプリのインストールをご覧ください。

2. 権限を許可する

Mac の「システム設定」→「プライバシーとセキュリティ」で、Remones Host に次の 2 つを許可します。

  • 画面収録とシステムオーディオ録音 — Mac の画面を iPhone に映すために必要です。
  • アクセシビリティ — iPhone から Mac を操作するために必要です。画面を見るだけなら、なくても使えます。

許可したら、Remones Host をいったん終了して開き直します。

3. Mac を追加する

iPhone・iPad で Remones を開き、Home の「＋」をタップします。Mac の追加方法は 3 つあります。

近くのMac

同じネットワークにある Mac が自動で表示されます。選ぶだけです。

アドレスを入力

Mac の IP アドレスかホスト名を入力します。ポートは空欄のままで通常は問題ありません（既定は 7777）。

Tailscale

Mac の Tailscale 上の名前か、100. で始まるアドレスを入力します。詳しく

はじめて Mac を探すとき、iPhone に「ローカルネットワーク上のデバイスの検索」についての確認が表示されます。「許可」を選んでください。あとから変えるときは、iPhone の「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で Remones をオンにします。

4. Mac で承認する

iPhone にペアリングコードが表示されます。Mac にも確認が表示されるので、同じコードであることを確かめてから承認します。

  • Always Allow — この iPhone を登録し、次回から承認なしで接続します。
  • Approve Once — 今回だけ許可します。
  • Reject — 拒否します。心当たりがない場合はこちらを選んでください。

5. 開く

Home に Mac が「オンライン」と表示されたら、「開く」をタップします。これで準備は完了です。

使いはじめのヒント

  • セッション中のメニューから Display（表示）、Input（入力）、Audio（音声）を切り替えられます。
  • シェルフを開くと、ほかのウインドウ、アプリ、Mac にすぐ移れます。
  • Home に戻っても、Mac との接続は保たれます。
  • iPhone でコピーしたテキストは、Input の「ペースト」で Mac に送れます。

うまくいかないときは うまくいかないとき、または サポートをご覧ください。

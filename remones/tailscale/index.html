外出先から使う（Tailscale）

Remones は、iPhone と Mac が直接つながるアプリです。自宅の外から使うときは、iPhone と Mac を同じ VPN に参加させます。ここでは Tailscale を使う方法を説明します。

このページの内容

  2. 設定の手順
  3. 手動で追加する
  4. 安全に使うために

しくみ

Tailscale は、自分の端末どうしをつなぐ VPN サービスです。iPhone と Mac を同じ Tailscale のネットワーク（tailnet）に参加させると、離れた場所からでも Mac に届くようになります。

Remones は、近くにいるときは同じネットワーク（LAN）の経路を、届かないときは Tailscale の経路を使って接続します。Remones のサーバーを経由することはありません。Tailscale の利用は任意で、ほかの VPN でも使えます。

設定の手順

  1. Tailscale を両方に入れる

    iPhone（または iPad）と Mac の両方に Tailscale をインストールします。Tailscale のダウンロード

  2. 同じアカウントでサインイン

    両方の端末で同じ Tailscale アカウントにサインインし、同じ tailnet に参加させます。両方で Tailscale がオンになっていることを確認してください。

  3. 一度、同じ Wi-Fi で接続する

    Mac で Tailscale がオンの状態で、同じ Wi-Fi にいるときに Remones で一度 Mac に接続します。このとき iPhone は、Mac の Tailscale 上のアドレスを覚えます。

  4. 外出先で開く

    外出先では iPhone の Tailscale をオンにして、Remones の Home からいつもどおり Mac を開きます。

Tailscale の使い方は Tailscale のドキュメントもご覧ください。

手動で追加する

同じ Wi-Fi で接続できない場合は、Tailscale のアドレスを直接入力して追加できます。Home の「＋」から、アドレス欄に次のどちらかを入力します。

  • Mac の Tailscale 上の名前（MagicDNS 名）。短い名前でも、完全な名前でも入力できます。
  • 100. で始まる Mac の Tailscale アドレス。

Mac の名前とアドレスは、Mac の Tailscale アプリで確認できます。MagicDNS については Tailscale の MagicDNS の説明をご覧ください。はじめて接続するときは、Mac での承認が必要です。

安全に使うために

Mac のポート（既定は 7777）を、ルーターのポート開放などでインターネットに直接公開しないでください。外から使うときは、Tailscale などの VPN を使ってください。

通信は TLS で暗号化され、ペアリング済みの端末だけが接続できます。接続できる端末は、Mac の Remones Host で確認・削除できます。

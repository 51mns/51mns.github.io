ダウンロード

Remones は、操作する側の iPhone・iPad と、操作される側の Mac の両方にアプリを入れて使います。

  • iPhone・iPad

    近日公開

    Remones 本体です。Mac を探して接続し、操作します。

    対応 OS
    iOS / iPadOS 18 以降
    配布
    App Store
    App Store で近日公開（まだ公開されていません）

  • Mac（Remones Host）

    準備中

    操作される側の Mac に入れるアプリです。iPhone・iPad からの接続を受け付け、画面と音声を送ります。

    対応 OS
    macOS 15 以降
    配布
    GitHub Releases
    Mac アプリを入手
